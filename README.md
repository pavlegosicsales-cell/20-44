# 20/44

Sajt za klub 20/44. Živo: https://20-44-phi.vercel.app

## Novi uredjaj

1. Treba samo [Node.js](https://nodejs.org) (LTS) i Git.
2. VS Code → Clone Repository → `https://github.com/pavlegosicsales-cell/20-44.git` → Open.
3. Na pitanja „Trust the authors" i „Allow automatic tasks" klikni **Allow / Yes**.

VS Code sam pokreće `tools/setup.mjs` (git remoti, pull, `npm install`) i dev server
na http://localhost:3000. Ceo kontekst projekta za Claude je u `CLAUDE.md`.

Ručno: `node tools/setup.mjs`, pa `npm run dev`.
